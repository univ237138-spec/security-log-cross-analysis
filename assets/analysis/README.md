# 분석 그래프

[생성 코드](make_eda.py)는 `data/`의 결과 파일을 읽어 분포·위험점수·단계별 건수를 그린다. 분석 결과를 다시 계산하지 않고 차트용 집계를 수행한다.

실행: `python assets/analysis/make_eda.py` (저장소 최상위). 현재 PNG를 덮어쓴다. 원본 코드는 Windows의 Malgun Gothic 글꼴을 사용한다. 다른 OS에서는 설치된 한글 글꼴로 설정해야 한다.
