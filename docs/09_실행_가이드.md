## 환경

Python 3.14 환경에서 검증한다. CSV 읽기·파싱·정규화·세션·탐지·위험점수·조사 코드는 표준 라이브러리를 사용한다. 통계 검정에는 scipy, 그래프 재생성에는 matplotlib·numpy·pandas가 필요하다. 실제 확인된 버전은 requirements.txt에 기록한다.

```bash
python -m venv .venv
# Windows PowerShell
.venv/Scripts/Activate.ps1
python -m pip install -r requirements.txt
```

명령은 저장소 최상위에서 실행한다. 각 처리 단계는 해당 산출 파일을 덮어쓰므로 팀 변경사항을 먼저 커밋한 뒤 재생성 결과를 비교한다. 원시 데이터는 입력으로만 읽는다.

## 전체 재생성 순서

```bash
python scripts/run_all.py
python scripts/03_apply_event_action.py
python scripts/99_verify_event_action.py
python scripts/04_integrate.py
python scripts/99_verify_integrated.py
python scripts/05_enrich.py
python scripts/06_link_classify.py
python scripts/07_sessionize.py
python scripts/08_baseline.py
python scripts/09_detect.py
python scripts/10_risk.py
python scripts/11_investigate.py
python scripts/12_stat_tests.py
```

`run_all.py`는 로그 4종의 파싱·초기 정규화 및 `99_verify.py`까지만 실행한다. `03_apply_event_action.py` 이후는 위 순서로 따로 실행한다. 통계 검정은 세션 결과에 의존한다.

조사 코드는 `docs/14_조사/01_사고카드.md`를 로컬에 생성할 수 있다. 이 파일은 Git 추적에서 제외되고, 조사 CSV 4개는 추적한다.

## Snowflake SQL

[SQL 안내](../sql/snow/README.md)의 점검 쿼리·내보내기 절차를 따른다. SQL을 Snowflake에서 직접 실행한 검증과 Python에서의 로컬 비교는 구분한다. 기존 SQL 문서에 기록된 직접 실행 미검증 상태를 유지한다.

## 그래프 재생성

## 검증 기록

2026-10-07, 별도 복사본에서 위 전체 재생성 순서의 13개 명령을 실행했다.

| 파싱부터 조사·통계 검정까지 실행 | 13개 명령 모두 종료 코드 0 |
| 재생성 후 데이터 일치 | CSV 45개 모두 기존 스냅샷과 바이트 단위 일치(수신 원본 4개 보존 포함) |
| 원본 프로젝트 대비 업로드 데이터 | CSV 45개 모두 바이트 단위 일치 |
| Python 구문 확인 | 포함된 Python 파일 전체 통과 |
